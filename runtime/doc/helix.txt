                           SPIDER REFERENCE MANUAL


Spider							*spider*

Spider is Neovim with the Helix editor's keymap and selection model:
"selection first, then action". Everything else (LSP, tree-sitter,
diagnostics, options, Ex commands, Lua API, plugins) is Neovim's, so Neovim
plugins and configs work. On top of that Spider adds, enabled by default:
- Helix keys, multiple selections and minor modes		|helix-mode|
- a popup command-line					|cmdline-popup|
- language servers started automatically when installed	|lsp-autodetect|
- a yazi-style file explorer (<Space>e)			|file-explorer|
- an API to adapt plugins to the selection model		|helix-api|

Spider runs as `spider`, keeps its config in `~/.config/spider` (`init.lua`)
and its data in `~/.local/share/spider` (|stdpath()|; set $NVIM_APPNAME to
use another name), so it can be installed next to Neovim.

New to it? Press <Space>? to search all commands, or a prefix key (g, m, z,
<Space>, [, ], CTRL-W) to see what follows.

==============================================================================
Helix mode						*helix-mode* *helix*

Spider uses the Helix editor's keymap and selection model by default:
"selection first, then action". Everything else (LSP, tree-sitter,
diagnostics, options, Ex commands, plugins) is the same Nvim.

Reference: https://docs.helix-editor.com/keymap.html

                                      Type |gO| to see the table of contents.

==============================================================================
Enabling and disabling					*helix-mode-enable*

Helix mode is part of Nvim's defaults (like |default-mappings|), controlled
by the 'helix' option, which is on by default. To use the Vim keys, put this
in your config: >vim
    set nohelix
<
'helix' can be toggled at any time; ":set nohelix" restores the Vim keys and
the |default-mappings| that Helix mode replaced. Setting the environment
variable `$NVIM_HELIX_MODE` to "0" resets 'helix' at startup.

Like other default mappings, mappings in your config take precedence: >lua
    vim.keymap.set('n', 'Q', 'gq')
<
Every Helix command is available as a Lua function, named like in Helix, to
rebind keys: >lua
    local cmds = require('vim._core.helix').commands
    vim.keymap.set('n', '<C-p>', cmds.file_picker.fn)
<
Variables:
- `g:helix_infobox` = |v:false|: don't show the key hints popup for minor
  modes (g, m, z, Space, …).
- `g:helix_jump_label_alphabet`: labels for |helix-gw| (default
  "abcdefghijklmnopqrstuvwxyz").

When enabled, Helix mode adds "onemore" to 'virtualedit' (selections can
include line endings), shows the mode (NOR, SEL, INS) in the default
'statusline', and replaces the |default-mappings| that would shadow Helix
keys (|]d|, |[<Space>|, |gc|, |grn|, …).

==============================================================================
Selections						*helix-selections*

A selection is an anchor and a head (the cursor). Motions select text: "w"
selects to the next word, then "d" deletes it. A 1-character selection is just
a cursor. The primary selection's head is the Nvim cursor.

There can be many selections (e.g. "%" then "s" with a regex). Edits, yanks
and pastes apply to every selection; Insert mode types at every selection
(using |multicursor|). Undo is atomic.

Moving the cursor by other means (mouse, LSP jumps, Ex commands) collapses the
selections to the cursor. A Visual-mode selection (mouse drag) becomes a Helix
selection.

The primary selection is also stored in the |'<| and |'>| marks, so
":'<,'>" Ex commands work on it.

Highlight groups:
- *hl-HelixSelection*        selections (links to |hl-Visual|)
- *hl-HelixSelectionPrimary* the primary selection (links to |hl-Visual|)
- *hl-HelixCursor*           cursors of non-primary selections (|hl-MCursor|)
- *hl-HelixJumpLabel*        labels of |helix-gw| (links to |hl-Search|)

Normal mode						*helix-normal*

Counts work as in Helix: "3w", "5G", "2>".

Movement ~
  h, <Left>        move left               j, <Down>      move down
  k, <Up>          move up                 l, <Right>     move right
  w / b / e        next word start / previous word start / next word end
  W / B / E        same for WORDs
  f / t {char}     find / till next char (across lines)
  F / T {char}     find / till previous char
  {n}G, {n}gg      go to line {n}
  Alt-.            repeat last motion (f, t, [, ])
  <Home> / <End>   line start / end
  CTRL-B, <PageUp> / CTRL-F, <PageDown>    page up / down
  CTRL-U / CTRL-D  half page up / down (or scroll an LSP popup)
  CTRL-I, <Tab> / CTRL-O   jump forward / backward on the |jumplist|
  CTRL-S           save selection to the jumplist

Changes ~
  r {char}         replace each selected char
  R                replace selection with yanked text
  ~ / ` / Alt-`    switch case / lowercase / uppercase
  i / a            insert before / append after selection
  I / A            insert at line start / end
  o / O            open line below / above
  .                repeat last insert
  u / U            undo / redo
  Alt-u / Alt-U    move backward / forward in history (|:earlier|, |:later|)
  y / p / P        yank / paste after / paste before
  " {reg}          select register for the next yank, paste, delete, …
  > / <            indent / unindent
  =                format selection (LSP range formatting, else |=|)
  d / Alt-d        delete (without yanking)
  c / Alt-c        change (without yanking)
  CTRL-A / CTRL-X  increment / decrement number
  Q / q            record / replay macro (register "@" by default)
  CTRL-Z           suspend

Shell ~
  |                pipe selections through a shell command, replace them
  Alt-|            pipe selections into a shell command, ignore output
  !                insert shell command output before selections
  Alt-!            append shell command output after selections
  $                keep selections for which the command exits 0

Selection manipulation ~
  s                select regex matches inside selections
  S                split selections on regex matches
  Alt-s            split selections on newlines
  Alt--            merge selections
  Alt-_            merge consecutive selections
  &                align selections in columns
  _                trim whitespace from selections
  ;                collapse selection to a cursor
  Alt-;            flip anchor and head
  Alt-:            make selections face forward
  ,                keep only the primary selection
  Alt-,            remove the primary selection
  C / Alt-C        copy selection to the next / previous line (add cursor)
  ( / )            rotate primary selection backward / forward
  Alt-( / Alt-)    rotate selection contents backward / forward
  %                select the whole file
  x                select line, extend to next line if already selected
  X / Alt-x        extend / shrink selection to line bounds
  J / Alt-J        join lines (and select the inserted spaces)
  K / Alt-K        keep / remove selections matching a regex
  CTRL-C           comment / uncomment
  Alt-o, Alt-Up    expand selection to the parent syntax node
  Alt-i, Alt-Down  shrink selection
  Alt-p, Alt-Left  select previous sibling node
  Alt-n, Alt-Right select next sibling node
  Alt-a            select all sibling nodes
  Alt-I, Alt-S-Down   select all children nodes
  Alt-e / Alt-b    move to end / start of the parent node

Search ~
  / / ?            search forward / backward (selects the match)
  n / N            select next / previous match (in select mode: add it)
  *                search for the selection (with word boundaries)
  Alt-*            search for the selection

Regexes use Helix (Rust regex) syntax: `\d+`, `(a|b)`, `\b`, `a+?`, … They
are translated to Vim regexes (|/\v|). A pattern starting with `\v`, `\m`,
`\V` or `\c` is used as a Vim pattern unchanged. Lowercase patterns are
case-insensitive (smart case).

Minor modes ~
  v                select (extend) mode: motions extend selections
  g                goto mode       |helix-goto|
  m                match mode      |helix-match|
  :                command mode
  z / Z            view mode / sticky view mode   |helix-view|
  CTRL-W           window mode     |helix-window|
  <Space>          space mode      |helix-space|
  [ / ]            unimpaired      |helix-unimpaired|

The key hints popup lists the keys of each minor mode.

							*helix-match*
Match mode (m) ~
  m                matching bracket
  s {pair}         surround with {pair} (brackets pair up)
  r {from}{to}     replace surrounding pair
  d {pair}         delete surrounding pair
  a {obj} / i {obj}    select around / inside a text object:
    w, W, p        word, WORD, paragraph
    {pair}         a pair (see below)   m   closest surrounding pair

    f, t, a, c, T, e, x   function, type, argument, comment, test, entry,
                   (X)HTML element (tree-sitter)
							*helix-pairs*
A {pair} is a pair character, or a letter for it (like vim-surround and
targets.vim):
    ( ) b    parentheses          " d      double quotes
    { } B    braces               ' s      single quotes
    [ ] r    brackets             ` k      backticks
    < > A    angle brackets       q        closest quote (ms: " ")
    m        closest pair of any kind (mi, ma, mr, md)
Any other character surrounds with itself (`ms*` makes *text*).
Examples: `mib` selects inside parentheses, `msB` surrounds with braces,
`mrbr` turns ( ) into [ ], `mdq` deletes the closest quotes.

  h j k l          go to window          H J K L     swap window
  q, CTRL-Q        close window          o, CTRL-O   only this window
  n s / n v        new split / vertical split with a scratch buffer

Insert mode						*helix-insert*

  <Esc>            back to Normal mode
  CTRL-S           commit undo checkpoint
  CTRL-X           completion ('omnifunc', e.g. LSP)
  CTRL-R           insert register
  CTRL-W, Alt-<BS> delete previous word
  Alt-d, Alt-<Del> delete next word
  CTRL-U / CTRL-K  delete to line start / end

  CTRL-D, <Del>    delete next char
  CTRL-J, <CR>     new line

							*helix-emacs*
Emacs keys (where Helix and Nvim don't use the key for something else):
  CTRL-A / CTRL-E  beginning / end of line (CTRL-E cancels completion)
  CTRL-F / CTRL-B  forward / backward char
  CTRL-N / CTRL-P  next / previous line (completion item when the menu shows)

File explorer					*file-explorer* *:Explorer*

A file manager with yazi's keys, in three floating columns: the parent
directory, the current directory and a preview of the hovered file or
directory. Open it with <Space>e (workspace root) or <Space>. (directory of
the current file, hovering it), or:

:Explorer [dir]		Open the explorer in [dir] (default: the directory
			of the current file).

Keys (as in yazi):
  j / k, <Down> / <Up>    down / up         J / K    down / up 5
  gg / G                  top / bottom      CTRL-D / CTRL-U  half page
  h, <Left>, -            parent directory
  l, <Right>, <CR>, o     enter directory / open file
  CTRL-S / CTRL-V / CTRL-T   open in split / vertical split / tab
  <Space>                 select (and move down)
  CTRL-A / CTRL-R         select all / invert selection
  <Esc>                   clear selection or filter, else close
  q, CTRL-C               close
  a                       create a file, or a directory when the name
                          ends with "/" (parents are created)
  r                       rename
  d                       move to the trash ("trash", "trash-put", "gio"),
                          or delete if none is installed (asks first)
  D                       delete permanently (asks first)
  y / x                   yank (copy) / cut the selected or hovered files
  Y, X                    cancel yank/cut
  p / P                   paste (copy or move) here / overwriting existing
  .                       show/hide hidden (dot) files
  ~ / g.                  home directory / working directory
  / / ?, n / N            find by name forward / backward, next / previous
  f                       filter the listing by name
  cc / cd / cf / cn       copy path / directory / file name / name without
                          extension to the clipboard
  ;                       run a shell command in the directory ("$@" are the
                          selected files, "$0" the first one)
  R                       reload
  <F1>                    show the keys

Selections and the yank/cut list survive changing directories; the yank list
and hidden-file setting are remembered when the explorer is reopened.

The |dir| listing (":edit {dir}") also gets yazi-style h / l / q keys in
Helix mode, and "e" opens the explorer there.

Plugins and the Lua API					*helix-api* *vim.helix*

Plugins keep working in Helix mode: they are still Nvim plugins, and their
mappings take precedence over Helix keys. The `vim.helix` module provides
adapters to make Vim-style plugin features behave the Helix way, so a plugin
(or your config) can be "Helix-ified" with a few lines.

Positions are `{row, col}`, 0-indexed, `col` a byte index (|api-indexing|). A
selection is `{ anchor = pos, head = pos }`, both ends inclusive; the head of
the primary selection is the cursor.

Selections ~
vim.helix.enabled()                                   *vim.helix.enabled()*
    True when 'helix' is set.
vim.helix.mode()                                         *vim.helix.mode()*
    "normal", "select" or "insert".
vim.helix.set_mode({mode})                           *vim.helix.set_mode()*
    Sets "normal" or "select" mode.
vim.helix.get_selections()                     *vim.helix.get_selections()*
    Returns the selections of the current buffer (in buffer order) and the
    index of the primary one.
vim.helix.set_selections({selections}, {primary})
                                               *vim.helix.set_selections()*
    Replaces the selections; overlapping ones are merged.
vim.helix.get_text()                                 *vim.helix.get_text()*
    Returns the text of each selection.

Events ~
							*HelixModeChanged*
User HelixModeChanged      After switching between normal and select mode.
                           |event-data|: `{ old = mode, new = mode }`.
							*HelixSelectionChanged*
User HelixSelectionChanged After the selections changed (at most once per
                           event-loop iteration).

Adapters ~
vim.helix.motion({fn}, {opts})                         *vim.helix.motion()*
    Returns a mapping callback that runs {fn}, a function moving the cursor
    (a jump, search or "go to" of a plugin), and turns the result into a
    selection: collapsed at the target, or from the old cursor with
    `{ range = true }`, or extended in select mode. A Visual selection made
    by the plugin becomes the selection. Asynchronous motions are handled.
vim.helix.operator({op}, {opts})                     *vim.helix.operator()*
    Returns a mapping callback applying a Vim operator to every selection.
    {op} is the keys of a Visual-mode command or plugin mapping (run with
    mappings enabled, Visual mode linewise for whole-line selections, or
    `{ linewise = true/false }`), or a function receiving each selection's
    range `{ start = pos, end_ = pos, linewise = bool }`. Afterwards each
    selection covers the changed text.
vim.helix.textobject({key}, {spec})                *vim.helix.textobject()*
    Adds `m a {key}` / `m i {key}` text objects. `spec.around`/`spec.inner`
    are the keys of a Vim text object (e.g. a plugin's "af") or a function
    from a range to a range (or nil). `spec.desc` shows in the key hints.

Keys and commands ~
vim.helix.map({menu}, {lhs}, {rhs}, {desc})               *vim.helix.map()*
    Maps {lhs} in "normal" mode or in a minor mode: "goto", "match", "view",
    "window", "space", "[" or "]". {rhs} is a function or the name of a
    Helix command. Minor-mode keys appear in the key hints popup.
vim.helix.unmap({menu}, {lhs})                          *vim.helix.unmap()*
    Removes a key added by Helix mode or |vim.helix.map()|.
vim.helix.commands()                                 *vim.helix.commands()*
    Returns the Helix commands by name (as in Helix: "file_picker",
    "select_regex", …): `{ fn = function, desc = string, keys = string }`.
vim.helix.add_command({name}, {fn}, {desc})       *vim.helix.add_command()*
    Adds a command, listed in the command palette (<Space>?) and usable by
    name in |vim.helix.map()|.

Pickers ~
vim.helix.pick({opts})                                   *vim.helix.pick()*
    Opens the builtin picker. {opts}: `title`, `items` (`{ text, file?,
    buf?, lnum?, col?, action? }`), or `dynamic` (function from the query
    to items), `on_select(item, how)`, `preview`.
vim.helix.set_picker({fn})                         *vim.helix.set_picker()*
    Uses {fn}({opts}) as the UI for every Helix picker (files, buffers,
    symbols, diagnostics, …); it must call `opts.on_select(item, "edit")`
    for the chosen item. nil restores the builtin picker.

Recipes ~
Jump plugins (hop, leap, flash, …): wrap the jump as a motion: >lua
    vim.keymap.set('n', 'gj', vim.helix.motion(function()
      require('flash').jump()
    end))
<
Operator plugins (comment, surround, sort, replace-with-register, …): use
their Visual-mode mapping on all selections: >lua
    -- nvim-surround's Visual-mode "S", on every selection:
    vim.keymap.set('n', 'gS', vim.helix.operator('S'))
<
Text object plugins (tree-sitter textobjects, mini.ai, …): >lua
    vim.helix.textobject('o', { around = 'ao', inner = 'io', desc = 'Loop' })
<
Picker plugins (Telescope, fzf-lua, …): put them on Space-mode keys, or use
them for all Helix pickers: >lua
    vim.helix.map('space', 'f', function()
      require('telescope.builtin').find_files()
    end, 'Find files')
    vim.helix.set_picker(function(opts)
      vim.ui.select(opts.items or {}, {
        prompt = opts.title,
        format_item = function(item) return item.text end,
      }, function(item)
        if item then opts.on_select(item, 'edit') end
      end)
    end)
<

Differences from Helix					*helix-differences*

- Helix text objects and `]f`-style motions use tree-sitter textobject
  queries; Nvim recognizes the node kinds by name instead, which works for
  most grammars.
- "j" and "k" move by text lines, not wrapped screen lines.
- <Space>G (debugging) needs a DAP plugin.
- The signature-help popup can't cycle signatures (Alt-p/Alt-n).
- Ex commands are Nvim's (|:w|, |:q|, …), not Helix's typable commands.
- Vim keys without a Helix binding (D, Y, H, L, M, 0, …) do nothing.
